## 设计原则

1. **快节奏，不是高压**：每 10–20 秒有反馈，每轮 60–90 秒，没有失败惩罚。
2. **一键上手**：只点击/触摸窗户；复杂操作不超过一个“按住”。
3. **先好玩，再治愈**：先有连击、点亮、收集、明信片，再谈情绪共鸣。
4. **深度藏在内容里**：不在游戏里讲心理学，不诊断、不说教。
5. **AI 是机制**：AI 生成每一晚的天气、节奏、窗后小景和结尾文案。
6. **大受众**：不需要心理学知识，不收集隐私，不强制表达。
7. **卡通油画**：CA 定调 + Blender 出质感 + Three.js 出交互，不写实、不科幻、不赛博。

## 灰盒验证结果（R1 预演）

已用真实浏览器验证：

- 24 扇窗正常渲染
- 发光窗可点击
- 点击有光、粒子、声音、温暖值变化
- 连击正常累计
- 连击 3 触发邻窗发光
- 温暖值达到 100 触发全楼亮起
- 庆祝后恢复可点窗，游戏可继续
- 故事窗可打开
- 故事窗不强制暂停夜晚
- 无浏览器控制台错误

### 验证中发现并修复的问题

1. 快速模式 12 秒太短 → 改为 20 秒
2. 发光窗不够明显 → 增加描边、外光晕、呼吸环
3. 故事窗持续缩放导致点击不稳定 → 改为只做光晕脉冲
4. 全楼亮起后无目标感 → 1.8 秒后恢复可点窗
5. 故事窗强制暂停打断节奏 → 改为可选浮层，夜晚继续
6. 重复点亮同一扇窗导致 `lit > 24` → 改为每窗每晚只计一次
