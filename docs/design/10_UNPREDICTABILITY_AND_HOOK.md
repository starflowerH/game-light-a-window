# 未知性、期待感与上头机制

> 目标：让游戏不只是“舒服”，而是有“下一扇窗会是什么”的期待。  
> 方法：可变奖励 + 窗后小景 + 夜间突变 + 明信片抽取 + 连续游玩。  
> 底线：不赌博化、不制造焦虑、不强迫打卡、不利用羞耻或损失厌恶。

---

## 1. 问题诊断

当前设计：

- 点击发光窗 → 点亮 → 连击 → 全楼亮起

优点：

- 易上手
- 反馈快
- 解压

问题：

- 可预测
- 每扇窗的奖励差异不大
- 缺少“下一次会是什么”的期待
- 容易在 2–3 分钟后腻

要像刷视频一样带劲，需要：

1. **不可预测的小奖励**
2. **稀有但不过分的东西**
3. **连续的小目标**
4. **每次都不一样的内容**
5. **看完一个还想看下一个**

---

## 2. 核心原则

### 2.1 可变奖励，而不是随机惩罚

- 奖励可以随机
- 惩罚不能随机
- 不让玩家因为运气差而失败
- 不让玩家觉得“错过就亏了”

### 2.2 小奖励高频，大奖励稀有

| 频率 | 奖励 |
|---|---|
| 每次点击 | 光、声、温暖值、连击 |
| 每 5–10 次 | 小彩蛋：窗后剪影、特殊音效 |
| 每 15–25 次 | 故事窗、小物件 |
| 每轮 1 次 | 夜间突变：整栋楼换天气/换配色 |
| 每 3 轮 | 稀有明信片 |
| 极低概率 | “今晚的特别窗” |

### 2.3 不制造“错失恐惧”

- 没有每日限定
- 没有倒计时礼包
- 没有连续登录惩罚
- 没有“错过就没了”的稀有窗
- 所有内容都可以以后再遇到

---

## 3. 六层未知性设计

### 3.1 第一层：窗后剪影（高频小惊喜）

每点亮一扇窗，有概率出现一个短暂的窗后剪影：

- 一杯冒热气的泡面
- 一只趴在窗台的猫
- 一盆绿萝
- 一把吉他
- 晾着的白球鞋
- 一个正在写字的人影
- 一盏旧台灯
- 一张贴纸

概率：

- 普通窗：15%
- 连击 5 以上：25%
- 故事窗：100%

表现：

- 窗亮后 0.15 秒，剪影淡入
- 停留 0.8 秒
- 淡出

作用：

- 每次点击都有可能“看到点什么”
- 不需要阅读
- 不打断节奏

### 3.2 第二层：声音彩蛋（听觉惊喜）

不同窗户有不同的声音：

| 窗户类型 | 声音 |
|---|---|
| 普通 | 木质轻响 |
| 绿萝窗 | 叶片沙沙 |
| 猫窗 | 很轻的喵 |
| 吉他窗 | 一个和弦 |
| 水壶窗 | 咕嘟声 |
| 雨棚窗 | 雨滴声 |

概率：

- 每扇窗固定类型，玩家不知道下一扇是什么
- 连击越高，声音越丰富

作用：

- 声音是“盲盒”
- 不需要看文字
- 适合快节奏

### 3.3 第三层：故事窗（中频内容惊喜）

故事窗不是固定时间出现，而是：

- 每点亮 8–12 扇窗，有概率触发
- 触发时，窗户出现金色边框
- 点开后是一句 8–24 字校园小景 + 一个小物件

概率控制：

- 每轮至少 2 次，最多 4 次
- 连击高时提高概率
- 不打断夜晚

作用：

- 每次玩都可能遇到不同的小景
- 文案是内容惊喜
- 可收集但不强制

### 3.4 第四层：夜间突变（轮内大惊喜）

每轮进行到约 50% 时，触发一次“夜间突变”：

- 天气突然变了
- 整栋楼的窗光颜色变了
- 背景音乐加入新层次
- 所有窗户短暂呼吸

示例：

- 小雨突然停了
- 风把云吹开，露出月亮
- 楼道灯忽然全亮
- 远处的操场灯亮了

作用：

- 打破重复
- 给玩家“发生了什么”的惊喜
- 不增加操作难度

### 3.5 第五层：特别窗（低频稀有奖励）

极低概率出现“特别窗”：

- 窗户不是普通暖黄，而是偏暖粉/暖绿/暖白
- 点开后出现一个特殊小景
- 获得一张特殊明信片边框

概率：

- 每轮约 5%
- 不保底
- 不影响通关
- 不制造“必须刷”的压力

作用：

- 提供“我今天遇到了”的分享欲
- 不破坏平衡

### 3.6 第六层：明信片抽取（轮末期待）

每轮结束生成明信片：

- 背景从 3–6 套中随机
- 文案从 20 条中随机
- 边框从 3 种中随机
- 小物件组合随机

作用：

- 每轮结束都有“这张会是什么样”的期待
- 明信片可保存/分享
- 不排名、不比较

## 4. 连续游玩设计（像刷视频一样）

### 4.1 一轮之后的钩子

结算页不要只给“再玩一次”，而是：

```text
今晚的明信片
[预览图]

下一晚的天气：
小雨 · 有风 · 晴

今晚遇到的小物件：
🌿 绿萝 · 🎧 耳机 · 🌙 月亮

[进入下一晚]
[再玩一次]
[保存明信片]
```

关键：

- 展示“下一晚可能不同”
- 展示“你还没遇到的小物件”
- 不显示“你还差多少”

### 4.2 三晚之后的钩子

三晚结束：

- 生成总明信片
- 显示本局收集到的小物件
- 显示“下次可能遇到”的剪影
- 提供“再来三晚”

不要：

- 每日签到
- 连续登录奖励
- 限时任务
- 排行榜压迫

### 4.3 快速重开

- “再玩一次”按钮必须在 1 秒内响应
- 不重新输入 Key
- 不重新加载页面
- 不重新看开场动画

### 4.4 可变开局

每次重新开始：

- 初始天气随机
- 第一扇发光窗位置随机
- 背景配色随机
- 故事窗内容随机

作用：

- 每次开局都有点不一样
- 不需要新内容也能有新鲜感

---

## 5. 奖励节奏表

| 时间 | 事件 | 目的 |
|---|---|---|
| 0–3s | 第一扇窗发光 | 立即上手 |
| 3–10s | 第一次点亮 + 声音 | 第一次爽感 |
| 10–25s | 连击 3/5 | 连击爽感 |
| 25–40s | 第一次故事窗 | 内容惊喜 |
| 40–55s | 夜间突变 | 打破重复 |
| 55–70s | 全楼亮起 | 高潮 |
| 70–75s | 明信片 | 收束与期待 |
| 结算 | 下一晚预览 | 继续游玩 |

## 7. 不能做的“上头”设计

- 抽卡付费
- 开箱
- 限时错过
- 连续登录惩罚
- 随机扣分
- 稀有度比较
- 排行榜羞辱
- 用“你不够好”驱动重玩
- 用焦虑、孤独或自我否定做钩子

---

## 8. 与心理健康的边界

- 不利用脆弱状态
- 不制造“只有玩这个才能好受”的依赖
- 不宣称疗效
- 不把随机奖励做成赌博
- 不鼓励熬夜刷
- 提供“今晚到这”按钮
- 结算文案允许离开

---

## 9. 验收标准

- 玩家每 10 秒至少有一次小惊喜
- 每轮至少 1 次中惊喜
- 每轮结束想看下一张明信片
- 玩家能说出“我刚刚看到一只猫/一盆绿萝”
- 不觉得被强迫继续
- 不觉得错过就亏
- 3 人测试中 2 人想再玩一轮
- 0 人说“像赌博”

---

## 10. 最终钩子

> 你永远不知道下一扇窗后面是什么。  
> 可能是一盆绿萝，一只猫，一盏旧台灯，  
> 也可能只是一句：“今晚的月亮，被云挡住了一半。”  
>   
> 但你知道，再点一下，总会有光。
