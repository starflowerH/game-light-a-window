# 验收清单与比赛映射

## 1. 体验验收

- [ ] 30 秒内可开始
- [ ] 第一次点击有光、有声、有粒子
- [ ] 60 秒内出现第一次连击
- [ ] 90 秒内出现第一张明信片
- [ ] 5 分钟内完成三晚
- [ ] 无失败惩罚
- [ ] 可暂停、可退出、可重开
- [ ] 声音可关闭
- [ ] 减少动画可开启
- [ ] 移动端可玩
- [ ] 键盘可操作

## 2. 内容验收

- [ ] 24 条故事窗
- [ ] 10 个小物件
- [ ] 3 套明信片
- [ ] 无心理学术语
- [ ] 无说教
- [ ] 无真实隐私
- [ ] 无自伤/自杀内容
- [ ] 允许“不完美”
- [ ] 每条故事 ≤ 24 字
- [ ] 每条明信片 ≤ 40 字

## 3. AI 验收

- [ ] Key 输入页
- [ ] Key 校验
- [ ] 三晚生成
- [ ] JSON Schema 校验
- [ ] 禁用词过滤
- [ ] 超时 fallback
- [ ] 非法 JSON fallback
- [ ] Key 不写 storage
- [ ] Key 不打印控制台
- [ ] Key 不发自建服务器
- [ ] 项目说明包含隐私说明

## 4. 工程验收

- [ ] 构建成功
- [ ] 无控制台错误
- [ ] 无 404
- [ ] 首屏 < 3s
- [ ] 总包 < 12MB
- [ ] Lighthouse Performance ≥ 80
- [ ] Accessibility ≥ 90
- [ ] 3 个浏览器通过
- [ ] 移动端通过
- [ ] 排行榜可关闭
- [ ] 健康检查正常
- [ ] README
- [ ] 素材清单
- [ ] 隐私说明
- [ ] 演示视频
- [ ] 1 页评审速览

## 5. 比赛奖项映射

| 奖项 | 本项目对应 |
|---|---|
| 最佳视觉设计 | 卡通油画夜景、24 扇窗、明信片 |
| 最佳交互体验 | 一键点亮、连击、光链、声音反馈 |
| 最佳 AI 技术应用 | 三晚生成、JSON 驱动、fallback、Key 隐私 |
| 最佳工程奖 | 静态前端 + 轻后端 + 部署 + 测试 + 文档 |

## 6. 发布前最后检查

- [ ] 无痕窗口完整走通
- [ ] 无 Key 也能离线玩
- [ ] 有效 Key 能生成三晚
- [ ] 断网时游戏不崩
- [ ] 手机横竖屏都不崩
- [ ] 明信片可下载
- [ ] 排行榜可关闭
- [ ] 项目说明可打开
- [ ] 所有素材有来源记录
- [ ] 提交包 < 30MB
