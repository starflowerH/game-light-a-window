关于举办“鸿雁云程·AI创世纪”创新创业大赛的通知 
一审：刘海军 二审：周熠 三审：唐斯萍 加入时间：[2026-04-01] 阅读次数：[ ] 
各二级学院： 
为进一步激发我校学生人工智能创新创业活力，推动人工智能应用与创新创业教育深度融合，学校决定面向全校学生举办“鸿雁云程·AI创世纪”创新创业大赛。现将有关事项通知如下： 
一、组织单位 
主办单位：衡阳师范学院创新创业与继续教育学院 
承办单位：衡阳师范学院计算机科学与技术学院、衡阳道芯融创文化科技有限责任公司 
二、参赛对象 
全校学生均可报名，不限专业、年级。可个人报名，也可自由组队参赛，每队不超过3人。 
三、活动主题 
AI+创意表达与数字内容创新实践。 
四、作品方向与参赛要求 
1. 参赛作品应围绕积极健康、适合校园传播的主题进行创作，鼓励 聚焦 AI短视频、AI漫剧、AI互动产品、AI公益传播、AI科普教育、AI游戏等方向开展创新实践。 
2. 作品可结合校园文化、地方文化、公益教育、心理成长、安全教育、青年表达等内容，突出思想性、创新性、传播性和应用价值。 
3. 作品形态包括AI短视频、AI漫剧、HTML/H5互动游戏、剧情游戏、叙事游戏、文字交互游戏、AI互动产品、AI公益传播产品、AI科普教育产品及其他适合线上展示与传播的数字作品。互动类作品原则上应具备在线体验条件 。 
4. 参赛作品必须集成 DeepSeek API。作品启动时须要求用户输入有效的 DeepSeek API Key，并在验证通过后方可进入核心互动流程。 
5. 用户输入的DeepSeek API Key仅用于当前作品功能逻辑调用，不得收集、上传、存储或他用 。 
6. 作品须在项目说明中明确写明 API Key 的使用方式、验证方式和隐私处理说明，确保可理解、可核查。 
7. 作品应保证在主流桌面浏览器环境下可正常打开、运行和体验 。 
8. 作品内容须坚持正确政治方向、价值导向和审美导向，符合国家法律法规和学校管理要求。所有素材须保证原创、授权或合规使用，AI生成内容须经人工审核和最终把关 。 
五、报名方式 
1. 报名时间：2026年3月31日至2026年4月7日。 
2. 报名链接：https://daoxin.fun/activity.html?id=9 
3. 参赛QQ群：1084253212。报名后请及时加入QQ群，后续赛事通知、培训安排、作品提交要求和答疑辅导等信息将在群内统一发布。 
4. 参赛个人或团队通过上述报名链接在线填写并提交报名信息，报名入口与作品提交入口为同一页面 。 
六、活动安排 
1. 启动发布阶段（2026年3月30日）：发布大赛通知，启动报名动员，同步开放活动页面与赛事说明 。 
2. 报名组队阶段（2026年3月31日至2026年4月7日）：组织学生报名、组队和方向确定 。 
3. AI训练营与选题辅导阶段（2026年4月11日至2026年4月17日）：围绕AI工具应用、作品策划、交互设计、API接入、上线部署等开展专题培训 。 
4. 团队创作阶段（2026年4月18日至2026年5月10日）：参赛团队完成创意打磨、原型设计、代码开发和内容完善 。 
5. 中期检查阶段（2026年5月11日至2026年5月14日）：组织阶段性检查与针对性辅导，及时优化方向和质量 。 
6. 作品提交阶段（2026年5月15日至2026年5月23日24:00）：参赛团队须在规定时间内完成线上提交，逾期未提交完整材料的，视为自动放弃评审资格 。 
7. 终审评议与成果布展阶段（2026年5月24日至2026年5月28日）：完成评审组织、结果汇总和展示准备 。 
8. 最终展示与颁奖阶段（2026年5月30日）：组织终审展示、颁奖交流和优秀成果发布 。 
七、作品提交要求 
1. 提交时间：2026年5月15日至2026年5月23日24:00。 
2. 提交方式：参赛个人或团队须通过报名链接所在页面提交作品，报名入口与作品提交入口为同一页面，不另设线下提交通道。 
3. 提交地址：https://daoxin.fun/activity.html?id=9 
4. 提交内容：作品名称、团队成员信息、作品简介、作品访问链接或在线体验链接、项目说明文档，以及必要的展示材料。项目说明中须包含AI工具使用说明、DeepSeek API接入说明和隐私处理说明。 
5. 互动类作品须确保链接可正常访问、可体验、可交互；视频类或展示类作品须保证播放链接有效、内容完整 。 
6. 参赛团队提交后应自行核对链接、材料和展示信息是否完整无误；因链接失效、材料缺失等影响评审的，责任由参赛团队自行承担 。 
八、评审与荣誉 
1. 大赛将围绕作品主题导向、创新创意、交互设计、技术实现、完成度和展示表达等维度进行综合评审。 
2. 优秀团队和个人可获得校级荣誉证书，优秀作品将有机会上线展示，并获得相关实习实践机会。 
3. 终审阶段将结合成果展示与颁奖交流，集中呈现优秀作品与学生创新创业风采。 
九、其他事项 
1. 各二级学院要高度重视，积极做好宣传动员、组织报名和过程指导工作。 
2. 参赛团队应严格遵守内容安全、数据安全、知识产权保护等相关要求，确保作品导向正确、技术合规、内容健康。 
3. 未尽事宜由主办单位另行通知。 
创新创业与继续教育学院
