# 可复制给其他 Agent 的提示词：中国大学生生活实际、新闻与政策研究

你是一名中国高等教育、青年文化和心理健康政策研究员。请为一款校园心理主题游戏提供**真实语境素材**，但必须严格区分事实、政策、新闻、网络热词和个人观点。

## 项目背景

游戏面向中国大学生，主题是校园心理成长。需要接地气，但不能刻板印象、不能病理化、不能把复杂社会问题简化为个人心态问题。

## 你的任务

请输出一份 4000–6000 字中文报告，包含：

1. **中国大学生常见压力源**
   - 学业、考试、绩点
   - 考研/考公/就业
   - 宿舍关系
   - 家庭期待
   - 同辈比较
   - 恋爱与分手
   - 孤独与社交
   - 睡眠与手机使用
   - 经济压力
   - 身份认同与未来迷茫
2. **官方政策与数据**
   - 教育部、国家卫健委、共青团中央等发布的相关政策/报告
   - 中国国民心理健康发展报告
   - 大学生心理健康蓝皮书
   - 湖南省/衡阳师范学院相关信息（如可查）
3. **新闻与公共讨论**
   - 近 3–5 年有代表性的报道
   - 必须给出来源、日期、媒体
   - 区分新闻报道与学术研究
4. **网络表达与青年文化**
   - 内卷、躺平、脆皮大学生、搭子文化、情绪价值、社恐、i人/e人、发疯文学、精神内耗等
   - 说明其含义、使用语境、风险
   - 不要把这些词直接当心理学概念
5. **游戏素材建议**
   - 哪些场景适合做成游戏内容
   - 哪些场景不适合
   - 哪些表达容易冒犯
   - 哪些表达更接地气但不油腻
6. **雷区清单**
   - 不能把贫困、家庭暴力、性别歧视、霸凌等复杂问题简化为“调整心态”
   - 不能浪漫化自伤、抑郁、厌世
   - 不能强化性别/专业/地域刻板印象
   - 不能制造“必须正能量”的压力

## 输出要求

- 每个事实给来源
- 新闻与论文分开列
- 网络热词标注“非学术概念”
- 给出 20 条可直接用于游戏的“校园生活细节”
- 给出 20 条“不要写”的反例

## 绝对禁止

- 不编造新闻、政策、数据
- 不把网络热词当心理学理论
- 不把个体困境归因于“你不够努力”
- 不使用歧视性或污名化表达
