# 设计约束：治愈系解压小游戏

## 定位

- 是：治愈系解压小游戏
- 不是：心理治疗、心理干预、心理测评、心理科普平台、心理健康综合工具

## 必须

- 好玩优先
- 有核心操作
- 有即时反馈
- 有可见状态变化
- 30 秒内能开始
- 5–15 分钟完成一轮
- 无失败惩罚或极低失败压力
- 可暂停、可退出、可重开
- 有声音反馈
- 有视觉统一性
- 有可重复游玩
- AI 是机制的一部分，不是聊天框
- Key 只存内存，不上传、不存储
- 有超时、重试、降级
- 有项目说明、隐私说明、素材清单
- 有危机内容安全出口

## 禁止

- 心理测评/诊断
- 宣称疗效
- 把负面情绪当失败
- 把“帮助”做成控制
- 把自伤/自杀做成关卡
- 把复杂问题简化为“想开点”
- 使用真实用户心事
- 前端硬编码 API Key
- 使用未授权素材
- 用伪科学作为核心理论
- 用心理学名词堆砌深度
- 用长文本说教代替玩法

## 文案语气

- 像朋友，不像老师
- 具体，不空泛
- 允许沉默和不确定
- 不强迫积极
- 不滥用网络热词
- 不写“你要坚强”“别人都可以你为什么不行”
- 结尾给选择，不给命令

## 可玩性最低标准

- 有明确操作对象
- 操作有即时视觉或声音反馈
- 环境或状态发生可见变化
- 有目标或进度
- 有结算
- 想再玩一轮

## 评分/排行榜

- 可以要，但不是必须
- 排名应基于玩家操作表现，不基于他人情绪改善
- 默认匿名
- 可关闭
- 不制造羞耻
