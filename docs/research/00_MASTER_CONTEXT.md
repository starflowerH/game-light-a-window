# 项目主上下文：心晴校园 AI 创意挑战赛 · 治愈系解压小游戏

> 更新时间：2026-11-08  
> 用途：给内容设计、心理学研究、技术实现提供统一背景。  
> 重要纠正：本项目是 **治愈系解压小游戏**，不是心理治疗、心理干预、心理测评或“支持方式匹配游戏”。

---

## 1. 项目定位

做一款面向大学生的：

- 治愈系
- 解压
- 浅显
- 接地气
- 有一点情绪共鸣
- 有一定深度，但不靠说教
- 浏览器直接玩
- 5–15 分钟能获得完整体验
- 有核心操作、即时反馈、状态变化、可重复游玩

**不是：**

- 心理治疗
- 心理干预
- 心理测评
- 心理科普平台
- 心理健康综合工具
- 通用 AI 树洞
- 需要学习心理学知识才能玩的作品

---

## 2. 一句话原则

> 先好玩，再治愈。  
> 心理学只做底层设计依据，不做游戏卖点。  
> 深度藏在机制和体验里，不写在说教文案里。

---

## 3. 游戏要满足的体验目标

玩家在 5–15 分钟内应该经历：

1. 一眼看懂要做什么
2. 做一个低压力但有反馈的操作
3. 看到环境或状态发生可见变化
4. 获得一点掌控感和完成感
5. 遇到一个轻微的情绪共鸣点
6. 结束时比开始时轻松一点
7. 愿意再玩一轮或分享结果

不要求玩家：

- 学会心理知识
- 改变认知
- 完成心理练习
- 暴露隐私
- 接受建议
- 被评分或诊断

### 投稿限制

- 必须有 HTML 入口。
- 可提交 Pinme 在线链接，或 ZIP/文件夹作品包。
- 作品包解压后总大小 ≤ 30MB。
- 需要封面图：PNG/JPG/WebP/GIF/SVG。
- 可包含 HTML/CSS/JS/JSON 及常见音视频。
- 投稿后进入管理员审核。
- 当前账号 `uploadEnabled=false`，需要联系主办方开通上传权限。
- 桌面浏览器优先，移动端不崩即可。

### 上一届评审维度

- 主题导向
- 创新创意
- 交互设计
- 技术实现
- 完成度
- 展示表达

### 上一届技术要求

- 必须集成 DeepSeek API。
- 启动时要求用户输入有效 API Key 并验证。
- Key 不得收集、上传、存储或他用。
- 项目说明中写明 API 使用方式、验证方式和隐私处理。
- 互动类作品应可在线体验。
- 素材须原创、授权或合规；AI 生成内容须人工审核。

> 本届是否完全沿用需继续核验，但实现时默认沿用。

## 5. 当前视觉与技术方向

### 视觉方向

- 低模 3D 校园夜间场景
- 柔和光影
- 雨、雾、云、灯光
- 统一色彩系统
- 明确视觉母题
- 不做通用白卡 UI

### 技术方向

- Vite + TypeScript
- Three.js 低模 3D
- DOM/CSS HUD
- WebAudio 环境音
- DeepSeek API 浏览器直连
- Key 只存内存
- 轻后端：Node.js + Fastify + SQLite
- Nginx + systemd + HTTPS
- 排行榜、匿名统计、健康检查
- 总包控制在 8–15MB

### 服务器

- 4 核 4G
- 已有多个项目，资源较紧
- 新服务必须轻量
- 可用域名：`hynu.site`、`xiaoxin.email`

## 6. 竞品结论

对 14 个已展示作品实机审查：

- 全部能打开，无控制台报错
- 多数是单文件 HTML
- 大量作品是“点击下一步 + 心理工具面板”
- 真正有游戏循环的只有少数
- 只有 1 个作品明确接入 DeepSeek，但 Key 明文写在前端，属于严重安全问题
- 主题高度同质化：树洞、呼吸、日记、测评、宿舍叙事

强对手：

- 心屿 · Isle of the Heart：视觉、叙事、音频、探索
- 四人一间：多结局叙事、回溯、工程完成度
- 拾光之旅：轻游戏循环、视觉氛围
- 心晴生物研究所：概念和视觉辨识度

### 机会

- 真正好玩的治愈系小游戏很少
- 真正把 AI 做成机制的作品几乎没有
- 大部分作品视觉统一性不足
- 大部分作品缺少完整工程交付

## 7. 设计原则

### 好玩优先

- 有核心操作
- 有即时反馈
- 有状态变化
- 有目标或进度
- 有可重复游玩
- 不是点击看文字

### 解压优先

- 低压力
- 无失败惩罚
- 可暂停
- 可退出
- 可控
- 环境变化可见
- 反馈及时
- 不用学习复杂规则

### 治愈感来源

- 柔和视觉
- 温暖声音
- 慢节奏
- 秩序恢复
- 小完成感
- 被陪伴感
- 不用动脑但有变化
- 允许不完美

### 文案原则

- 像朋友，不像老师
- 具体，不空泛
- 允许沉默和不确定
- 不强迫积极
- 不滥用网络热词
- 不写“你要坚强”“别人都可以你为什么不行”
- 结尾给选择，不给命令

---

## 8. 红线

- 不做诊断
- 不做治疗承诺
- 不宣称疗效
- 不做心理测评
- 不收集真实用户心事
- 不保存 DeepSeek Key
- 不把自伤/自杀做成普通关卡
- 不把复杂社会问题简化为“想开点”
- 不把“帮助”做成控制
- 不用未授权素材
- 不用伪科学作为核心理论

## 10. 判断标准

一个设计点进入游戏，必须同时满足：

1. 好玩
2. 30 秒内能理解
3. 5–15 分钟能完成一轮
4. 有清晰反馈
5. 不制造压力或羞耻
6. 不依赖心理学知识
7. 不靠说教表达深度
8. 实现成本可控
9. 视觉可统一
10. 评审能一眼看懂
