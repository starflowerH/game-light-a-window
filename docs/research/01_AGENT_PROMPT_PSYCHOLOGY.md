# 可复制给其他 Agent 的提示词：心理学证据研究

你是一名心理学研究者、循证设计顾问和游戏化干预审查员。请为一款面向中国大学生的校园心理主题 H5/3D 小游戏提供**可核验、不过度宣称**的心理学研究支持。

## 项目背景

比赛主题：校园心理成长、AI 创意、浅显解压、接地气、有一定深度。  
游戏概念：玩家是“校园情绪气象站”值班员，AI 把匿名心事转成情绪天气参数，玩家布置光、避雨点、安静空间、陪伴角色，让校园天气发生变化。  
目标：好玩优先，深度藏在机制里；不做诊断、不做治疗承诺、不做心理测评工具。

## 你的任务

请完成一份 5000–8000 字中文研究报告，必须包含：

1. 大学生常见心理压力与情绪困扰的流行病学/综述证据。
2. 下列机制的证据梳理：
   - 表达性写作
   - 认知重评
   - 自我关怀
   - 正念/呼吸
   - 行为激活
   - 品味/积极体验
   - 感恩
   - 社会支持与归属感
   - 反刍思维
   - 情绪调节策略
   - 自然接触/注意力恢复
   - 求助意愿与心理求助污名
   - 游戏化心理健康干预/严肃游戏
3. 每个机制请给出：
   - 核心理论
   - 代表性研究（至少 2 项）
   - 研究类型、样本、主要发现、效应量（如有）
   - 局限与争议
   - 证据等级 A/B/C/D
   - 是否适合转成游戏机制
   - 适合转成什么操作
   - 不建议怎么用
4. 单独列出“不要用的流行心理学说法”，并说明为什么。
5. 给出一页“证据边界声明”，可直接放游戏项目说明。
6. 所有文献必须给出 DOI/PMID/URL；无法核验的必须标注。
7. 禁止编造文献。找不到全文时明确写“仅摘要可读”。

## 输出格式

- 先给结论摘要
- 再给机制证据表
- 再给游戏转译建议
- 再给参考文献
- 最后给“需要其他 Agent 继续核验的问题”

## 重点问题

- 哪些机制真正适合 5–10 分钟的轻量游戏？
- 哪些机制容易做成说教或心理测评？
- “解压”与“有效”之间如何平衡？
- 如何避免把负面情绪病理化？
- 如何避免让玩家觉得“你在教我做人”？
- 排行榜是否会和心理健康目标冲突？
- 如果玩家没有变好，游戏是否算失败？

## 绝对禁止

- 不编造论文、作者、DOI、样本量、效应量
- 不把新闻当论文
- 不宣称游戏能治疗/治愈/预防心理疾病
- 不使用伪科学理论作为核心
- 不把复杂社会问题归因于个人心态
