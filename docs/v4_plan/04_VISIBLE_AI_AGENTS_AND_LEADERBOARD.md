# 04 · 显性 AI 智能体存在感、趣味随机昵称与精准定位排行榜设计

> **设计目标**：解决用户指出的「增强 AI 模型的运用和存在感」「玩家可自己取名，不取名自动随机给个名字」「打开榜就知道自己在哪一档/第几名」「4C4G 服务端持久化」四大需求。

---

## 一、 让玩家「看得见、玩得到」的 AI 智能体存在感架构

不再把 AI 藏在开局 Loading 里偷偷跑一次然后毫无痕迹！在 v4.0 中，我们把 **4-Agent 系统全面显性化、游戏化**：

### 1.1 界面上的「AI 校园夜巡台」实时状态条
- 在屏幕右上角或值班台面板嵌入一个精致的**像素油画风「AI 校务电台指示灯」**（显示当前模型来源：`DeepSeek 云端在线` / `自带 Key 直连` / `本地推演引擎`）。
- 每当 AI 实时工作时（如开场生成对话、生成特殊阵型关卡、触发随机事件、赛后点评），指示灯柔和呼吸并弹出轻巧提示：**`✦ AI 正在结合「研究生楼 · 冬雪夜」编排今晚巡楼事件…`**。

### 1.2 AI 在游戏核心流程中的 4 次高光介入

| 介入时机 | 负责智能体 | 具体产出与玩家体验感知 |
|---|---|---|
| **1. 开场 & 切换楼栋/天气时** | `DialogueDirector`（剧情对话官） | 根据你当前选的 **楼型（如高中楼）× 季节（冬）× 天气（雾）**，实时生成宿管阿姨与校领导的**专属开场对白**（例如冬雾天阿姨会叮嘱校领导戴好围巾、提醒同学别披着被子打游戏）。 |
| **2. 记忆模式 / 谜题模式每第 3 关** | `PuzzleArchitect`（AI 出题官） | AI 不再只出死文字，而是**亲自出题**！生成一组**语义化灯光阵型**（如记忆模式里拼出「小猫爪印」「北斗七星」「校门牌楼」的窗户坐标序列，附带一句 AI 提示语*「今晚 304 的橘猫在楼上踩出了一串梅花印，记住它的路线！」*），并动态根据玩家前两关准确率调节难度！ |
| **3. 局中突发随机事件时** | `EventNarrator`（校园广播员） | 触发随机事件时，AI 根据当前玩家连击数、失误次数实时播报一条极具画面感的突发小插曲（附带玩法 Buff/趣味变化）。 |
| **4. 闯关结束总结算时** | `InspectorCommentator`（AI 校领导 & 宿管复盘官） | 赛后结算面板里，**校领导和宿管阿姨会直接针对你这一局的真实数据写两句专属点评**！<br/>例如：*「依次亮起模式 94% 准确率、连着拿下第 8 关的北斗七星阵——周校长夸你记性比值班表还准！不过 405 室总是多点一次，是不是也想上去喝杯热茶？」* |

> **兜底不卡顿铁律**：所有 AI 请求均采用**「异步预生成 + 缓存池 + 完备本地规则无缝兜底」**（例如你在玩第 1 关时，后台已在悄悄预生成第 3 关的 AI 特殊阵型与对话），确保 100% 零等待卡死，同时最大限度展示 AI 实时参与感！

## 二、 自动随机昵称 + 全感知精准定位排行榜

### 2.1 昵称系统：可自定义 + 没填自动随机分配
1. **自动校园花名生成器（`generateCampusNickname()`）**：
   - 当玩家从未设置昵称、或清空输入框直接上榜时，不再全员千篇一律叫「今晚的某某」，而是从校园趣味词库随机组合（200+ 种组合），例如：
     - `四楼偷煮泡面的猫`、`天台借伞的学弟`、`102值班室常客`、`熬夜写不完论文星人`、`路灯下数飞蛾的同学`、`刚抢到最后一份关东煮`
   - 玩家首次进入可看到当前自动分配的昵称，并随时可点击旁边的「铅笔改名」或「骰子换一个随机名」图标。

### 2.2 打开榜单「立刻知道自己在哪」的精准排名架构
1. **多维度分榜筛选器（Tab Bar）**：
   - 支持按 **小游戏模式** 筛选：`记忆·依次顺序` / `记忆·同时快照` / `查寝夜猫子` / `全楼归眠解谜` / `星轨一笔画` / `综合总榜`
   - 支持按 **宿舍楼规模** 筛选：`全部楼栋` / `高中(18窗)` / `大学(24窗)` / `研究生(30窗)` / `员工(12窗)`
2. **顶部固定置顶「我的位置定位卡（My Rank Sticky Banner）」**：
   - 无论你排在第 1 名还是第 385 名，打开排行榜顶部永远高亮置顶一条专属定位卡片：
     ```text
     ┌────────────────────────────────────────────────────────────┐
     │ 🏅 你的当前定位：第 14 名 / 共 186 位守夜人（前 7.5%）      │
     │ 昵称：四楼偷煮泡面的猫 · 最高第 9 关 · 准确率 93.4% · 2,480分 │
     │ 💡 距离第 13 名「102热茶守护者」只差 120 分，再过一关就超越啦！│
     └────────────────────────────────────────────────────────────┘
     ```
   - 后端查询 SQL 直接通过窗口函数 `ROW_NUMBER()` 或 `COUNT(*) + 1` 计算出精确实时排名与总人数、百分位以及上一名分差（`nextGap`），4核4G SQLite 毫秒级返回！

## 三、 SQLite WAL v4.0 数据表扩展（兼容升级）

在现有 `server/db.js` 的 6 张表基础上，平滑升级兼容（`ALTER TABLE` 自动补列，绝不破坏已有数据）：

1. **`runs` 表新增字段**：
   - `game_mode TEXT NOT NULL DEFAULT 'star_sweep'`（`memory_sequence` | `memory_snapshot` | `patrol_reflex` | `lights_out_puzzle` | `star_sweep`）
   - `dorm_type TEXT NOT NULL DEFAULT 'university'`（`highschool` | `university` | `grad` | `staff`）
   - `season TEXT NOT NULL DEFAULT 'autumn'`
   - `weather TEXT NOT NULL DEFAULT 'clear'`
   - `stage_reached INTEGER NOT NULL DEFAULT 1`（闯关到达第几关）
   - `correct_count INTEGER NOT NULL DEFAULT 0`（累计准确点击数）
   - `accuracy_pct REAL NOT NULL DEFAULT 100.0`（准确率 `0.0 ~ 100.0`）
   - `score INTEGER NOT NULL DEFAULT 0`（模式综合得分，用于对应模式精准排序）
2. **新增复合索引**：
   - `CREATE INDEX IF NOT EXISTS idx_runs_mode_dorm_score ON runs(game_mode, dorm_type, score DESC, accuracy_pct DESC);`
3. **新增接口支持**：
   - `GET /api/leaderboard?mode=...&dormType=...&uid=...&limit=30` → 返回 `{ items, myRank: { rank, total, percentile, bestScore, bestAccuracy, bestStage, nextGap, nextNickname }, totalPlayers }`。
   - `POST /api/agent/dialogue` & `POST /api/agent/puzzle` & `POST /api/agent/debrief` → 对应 3 类高频互动型 AI 能力接口（同样支持用户自带 DeepSeek Key 浏览器直连）。
