## 一、 美术风格定调：Stardew 3D Diorama（星露谷立体像素油画风）

要实现**「既有星露谷的像素油画温度，又有 3D 写实立体结构与光影纵深，不糊成一团」**，必须对 `src/painterly.js` 与 `src/scene.js` 进行结构性升级：

### 1.1 材质与贴图策略（Pixel-Painterly PBR Hybrid）
- **核心秘诀**：在 Canvas 2D 程序化纹理生成器中（及可选外部 WebP），生成 **`64×64` 或 `128×128` 像素画基底 + 柔和油画笔触肌理** 的砖墙、木纹、瓦片、石板路、窗帘纹理，**关闭过度模糊，使用 `NearestMipmapLinearFilter` 或轻微像素锐化**，并配合 **真实的法线贴图（NormalMap）与粗糙度贴图（RoughnessMap）**！
- 这样一来：
  - 远看有**星露谷式的清晰瓦片、砖缝、木梁、像素树叶簇与温暖配色**；
  - 近看有**真实 3D 凹凸立体感、月光斜照下的檐口阴影（Real ShadowMap）、雨天湿润地面高光反射、路灯点光源暖照**！

### 1.2 重调 `src/painterly.js` 后期 Shader（告别过度涂抹，保留锐利像素油画细节）
- **Kuwahara 半径微调**：将原来的 `uKuwaharaRadius = 2.5` 降为 **`0.85 ~ 1.2`**（或通过 UI 风格开关在「星露谷像素锐利」与「厚涂油画微笔触」间调节），只柔和极细锯齿，**绝不糊掉砖瓦、窗棂与文字细节**。
- **可选微妙像素化网格融合（Subtle Pixel-Art Dither）**：保留 `strength = 0.25 ~ 0.45` 的暖色手绘墨线与纸张纤维高光，配合 `ACESFilmicToneMapping` + 柔和 `UnrealBloomPass`，让每一帧都像高配 HD-2D / 3D 星露谷截图！

### 2.2 统一交互节点规范（确保 4 款小游戏无缝兼容）
每一栋 GLB 模型在 Blender 中导出时**必须严格遵守同一套节点命名协议**：
- 所有可交互窗户玻璃节点命名为：`Window_Glass_<row>_<col>`（例如 `Window_Glass_0_0` 到 `Window_Glass_4_5`），并置于独立材质槽以便 Three.js 单独控制亮灭、颜色（暖黄 / 违规蓝紫 / 共鸣玫瑰金 / 提示绿）与 3D 视差内景平面挂载。

## 三、 校园集群布局、切楼动效与多视角系统

### 3.1 「附近宿舍楼」切换动效（告别生硬闪切！）
在 3D 场景中，不仅有当前焦点的宿舍楼，**左右与后方远景还摆放着另外几栋宿舍楼的低模剪影群落**，通过一条发光路灯点缀的**校园石板林荫大道**连接！
当玩家点击切换「高中宿舍 / 大学宿舍 / 研究生宿舍 / 员工宿舍」时，执行一套 **1.4 秒电影级跨楼转场动效**：
1. **阶段 1（0~0.5s）**：3D 相机沿平滑弧线向侧后方拉起并横移（模拟穿过林荫道树梢飞往隔壁楼），当前旧楼缓缓淡出或向左滑出景深；
2. **阶段 2（0.5~1.0s）**：目标新宿舍楼从远景顺着林荫道弹性缩放并微幅「微缩积木落位（Bounce Drop-in）」，路灯依次点亮引导视线；
3. **阶段 3（1.0~1.4s）**：宿管阿姨/校领导弹出「欢迎来到XX楼」语音气泡，完成切换！

### 3.2 四档看楼视角（Camera Presets）+ 阻尼自由微调
在屏幕右侧提供精致的相机图标切换栏，支持随时一键丝滑插值切换视角，并且支持鼠标左键/单指（非窗户区域或右键/双指）**限位自由旋转角度看楼**：
1. **`FRONT`（正面全景视角）**：正对楼面，玩记忆/棋盘小游戏最清晰。
2. **`STARDEW_ISO`（星露谷 45° 斜俯视视角）**：相机移至右上方斜 `38°~45°` 俯瞰整栋立体建筑、院落石板路、路灯与单车棚，最具星露谷立体小镇质感！
3. **`STREET_LOW`（林荫道仰望近景）**：贴近地面石板路向上仰视，能清晰看见屋檐、路灯丁达尔光束和窗台猫窝。
4. **`ROOFTOP_AERIAL`（天台航拍视角）**：掠过楼顶水塔、花房、晾衣绳与远方校园群楼轮廓。

## 四、 真实的「四季 × 五大物理天气」视觉重建

### 4.1 彻底重做「垃圾雾天」：真实多层次体积流雾（Real Volumetric Mist）
**绝对禁止再用雪花粒子假装雾！** 真实雾夜（`fog`）由以下 **4 层技术协同渲染**：
1. **6 层水平/斜向流动 FBM 体积雾带（Drifting Mist Planes）**：
   - 在草坪上方（`y = -210 ~ -80`）与半空（`y = -40 ~ +60`）放置多层半透明自定义 GLSL 着色器平面。
   - 着色器内部计算双层方向滚动的 Perlin FBM 噪声，边缘按相机视角与深度软淡化（Soft Depth Fade），**肉眼能清晰看到一缕缕乳青色夜雾正贴着地面草坪和宿舍一楼走廊缓缓流动！**
2. **光源米氏散射光晕（Mie Atmospheric Scattering Halos）**：
   - 当切换为雾天时，路灯下方挂载更大半径的指数雾散射光晕；每一扇点亮的窗户外围叠加一层柔和扩大的漫散射晕光，呈现「雾里看灯、光晕朦胧扩散」的真实光学美感。
3. **真实指数深度雾 + 远景楼群空气透视**：
   - 调整 `FogExp2` 仅作用于中远景群楼与远山，**不压暗近景主楼窗户的亮度与色彩**，确保近处依然立体通透、远处渐隐入雾！

### 4.2 其他 4 种天气真实表现
- **晴夜（`clear`）**：繁星闪烁、三层光晕满月（或弯月）、地面树影投射（开启 DirectionalLight Real ShadowMap）、清晰远山轮廓。
- **雨夜（`light_rain`）**：
  - 高速斜飞雨丝（带运动模糊拉长线）；
  - **地面水洼动态涟漪 Shader**：在地面石板纹理上叠加几十个随机周期扩散的同心圆法线涟漪，反射路灯和亮窗的倒影，地面粗糙度实时降为湿滑镜面感；
  - 后期玻璃轻微雨滴折射。
- **大风（`wind`）**：树木主干与枝叶、屋顶晾衣绳、横幅旗帜按真实风场频率摆动；空气中飘过对应季节的花瓣/落叶/萤火虫。
- **雪夜（`snow`）**：开启建筑屋檐/窗台/地面的 **3D 积雪覆盖层（Snow Cap Meshes）**；天空中缓慢飘落带大小透视与左右旋风摆动的片状雪花；宿舍烟囱与暖茶冒出可见白雾；路灯光色更显温暖对比。
